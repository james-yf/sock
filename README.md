A sokoban game.

# Aims:
- clean architecture, hopefully
- make it have a top-down view
- use my own pixel art

# What I learnt?
Most notable things were when making the editor. I wasn't familiar with python's file i/o,
and Bresenham's line drawing algorithm was an interesting thing to discover, although the 
math for it on the wiki went over my head. It got me to think about data serialisation, as
I had to decide on a format for levels to be stored in the file, and then how to pull them
in from the file to build grids out of them.
